# Student Database Management System

This is a simple student database system written in C. It allows the user to:

* Add student data.
* Delete a student by ID.
* List all Student IDs.
* Reads specific student's data by ID.
* Checks if an ID exists in database.
* Get used size of database.
* Check if Database is full.
* Exit the program 

Maximum number of students in Database is 10 and Minimum 3.


### How to set up and run project


#### Requirements
* GCC compiler.
* Git bash or any terminal that supports <code>make</code>

**1. Clone the repo**
```bash 
git clone https://github.com/habibashaker/Amit_c_project.git
cd Amit_c_project/
```

**2. Compile the code**
```bash 
make build
```

**3. Run the program**
```bash 
make run
```

**4. Clean the build file(optional)**
```bash 
make clean
```
